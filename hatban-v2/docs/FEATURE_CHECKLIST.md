# 햇반이네 v2 기능 체크리스트

이 문서는 legacy v1(`햇반이네_최종.html`)과 `AUDIT.md`, `PHASE2.md`를 기준으로 작성했다. v2에서 기능을 하나씩 구현할 때 기존 기능 누락과 저장 데이터 호환 여부를 확인하는 기준으로 사용한다.

표시 규칙:

- `[ ]` 미구현
- `[~]` 일부 구현
- `[x]` 구현 및 검증 완료

## 홈

- [~] 앱 제목과 로고/이모지 설정 — 프로필 이모지 설정 완료, 앱 제목 변경은 미구현
- [x] 오늘의 문구 자동 표시
- [x] 오늘의 문구 직접 수정 및 날짜별 저장
- [x] 테마 색상 변경 및 유지
- [x] 폰트 변경 및 유지
- [x] D-Day 이름과 날짜 설정
- [x] D-Day 남은 날짜 계산
- [x] 메모 생성, 수정, 삭제
- [x] 메모 색상 선택
- [ ] 메모 드래그 순서 변경 및 유지
- [x] 오늘의 자기평가 3개 항목

- [x] 날짜가 바뀔 때 자기평가 초기화
