# 햇반이네 v2

Vite와 Vanilla JavaScript로 새로 만드는 학급용 배움 앱이다. 현재 버전은 4개 최상위 화면과 반응형 navigation을 제공하는 프로젝트 기반이다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드 확인:

```bash
npm run build
```

## 현재 범위

- 홈
- 배움공책
- 학습 도우미
- 집중 게임
- hash 기반 화면 이동
- 모바일, 태블릿, PC 반응형 UI

실제 메모, Canvas, 도구, 게임, 서버 저장은 이후 단계에서 기능별로 구현한다. legacy v1 기능 목록은 `docs/FEATURE_CHECKLIST.md`에서 관리한다.
